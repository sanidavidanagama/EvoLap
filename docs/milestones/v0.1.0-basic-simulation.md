# Active Milestone: v0.1.0 — Basic Simulation & Manual Driving

**Status**: In Progress  
**Target Release**: `v0.1.0`  
**Git Feature Branch**: `feature/basic-sim`

---

## Objective
Establish the foundational simulation, physics, and rendering architecture with a single car and track under manual keyboard control. No AI or training features are included in this milestone.

---

## Submilestones & Checklist

### [x] Submilestone 1: Math & Geometry Foundation (`core/`)
- [x] Implement `Vector2D` with basic vector math (addition, subtraction, dot product, scaling, magnitude, normalization).
- [x] Implement `LineSegment` and line-intersection detection algorithms (`math2d.py`).
- [x] Add unit tests verifying 2D vector and intersection math.

### [x] Submilestone 2: Track Geometry & Representation (`simulation/track.py`)
- [x] Define track data structures: asphalt boundary loop, inner barrier, outer barrier.
- [x] Add Monaco-style test circuit coordinates with left and right turns.
- [x] Define start/finish line segment and spawn position/heading for car.

### [x] Submilestone 3: Vehicle Physics Dynamics (`physics/`)
- [x] Implement longitudinal dynamics: gradual throttle build-up, gradual deceleration / engine braking, reverse/brake.
- [x] Implement lateral dynamics: gradual steering response with angular damping.
- [x] Implement tire friction and rolling resistance.
- [x] Implement barrier collision checks against track line segments.
- [x] Implement crash transition (`status = "Out"`) 
- [x] Implement reset logic.
- [x] Create headless test script verifying car moves, turns, decelerates, and stops when controls change.

### [x] Submilestone 4: Simulation World (`simulation/`)
- [x] Implement `Car` state container (position, heading, velocity, steer angle, status).
- [x] Implement `World` with `step(dt)` and `reset()`.
- [x] Verify that `World.step(1/60)` runs 100% headless with zero Pygame dependency.

### [x] Submilestone 5: Pygame Rendering & Camera (`rendering/`)
- [x] Implement `TrackRenderer`: draws asphalt surface, kerbs, barriers, and checkered line.
- [x] Implement `CarRenderer`: top-down 2D F1 car shape with steerable front wheels.
- [x] Implement `Camera` system:
  - Mode 1: Full-Track Camera (fixed viewport framing the entire track).
  - Mode 2: Follow Camera (smoothly follows the car with forward lookahead offset).

### [x] Submilestone 6: Game Loop & Controls (`main.py`)
- [x] Map keyboard controls: `W`/`Up` (Throttle), `S`/`Down` (Brake), `A`/`Left` (Steer Left), `D`/`Right` (Steer Right).
- [x] Map utility keys: `C` (Toggle Camera), `R` (Reset Car).
- [x] Assemble the loop: Input $\to$ Simulation $\to$ Physics $\to$ State $\to$ Renderer.

### [x] Submilestone 7: Verification & Version Bump
- [x] Verify that manual driving feels smooth, responsive, and adheres to physics constraints.
- [x] Verify `pyproject.toml` version matches `0.1.0`.
